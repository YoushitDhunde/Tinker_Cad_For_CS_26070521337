# Arduino Tinkercad Projects

A collection of basic Arduino Uno circuits simulated in Tinkercad.

## Projects Included

### 1. Soil Moisture Irrigation System
Reads soil moisture levels to control a DC water pump via an NMOS transistor and displays status with three indicator LEDs.
* **Components:** Arduino Uno, Soil Moisture Sensor, DC Motor, NMOS MOSFET, 3x LEDs, Resistors
* **Simulation Link:** (https://www.tinkercad.com/things/avEohTNwJ6K-mighty-borwo)

### 2. Potentiometer LED Control
Uses a potentiometer as an analog input to adjust the brightness or blink rate of an LED.
* **Components:** Arduino Uno, Potentiometer, LED, Resistor
* **Simulation Link:** (https://www.tinkercad.com/things/8XQAGcxPiAE-fantastic-kasi-lahdi)
### 3. Light-Sensitive LED (LDR)
Detects ambient light using a photoresistor and automatically toggles an LED based on light levels.
* **Components:** Arduino Uno, Photoresistor (LDR), LED, 2x Resistors
* **Simulation Link:** (https://www.tinkercad.com/things/lnVafOpC3fo-photo-resistor)

### 4. DC Motor Control with L293D
Controls the speed and direction of a DC motor using an L293D motor driver IC.
* **Components:** Arduino Uno, DC Motor, L293D Motor Driver, Breadboard
* **Simulation Link:** (https://www.tinkercad.com/things/1cnlm48B2WH-dazzling-luulia)
### 5. 16x2 I2C LCD Display
Displays custom text and numbers on a 16x2 LCD screen using I2C communication (`A4` SDA, `A5` SCL).
* **Components:** Arduino Uno, 16x2 LCD (I2C)
* **Simulation Link:** (https://www.tinkercad.com/things/8hOKlchfOdB-frantic-krunk)

### 6. TMP36 Temperature Sensor
Reads ambient temperature data from an analog TMP36 sensor connected to pin `A0`.
* **Components:** Arduino Uno, TMP36 Temperature Sensor
* **Simulation Link:** (https://www.tinkercad.com/things/fCw74KKAtfu-shiny-kup)

### 7. Servo Motor Control
Controls the angular position of a micro servo motor using PWM on pin `9`.
* **Components:** Arduino Uno, Micro Servo
* **Simulation Link:** (https://www.tinkercad.com/things/3o1TFfuVZsI-swanky-duup-esboo)

### 8. Pushbutton LED Circuit
A basic hardware circuit on a breadboard where pressing a tactile pushbutton completes the circuit to light up an LED.
* **Components:** Arduino Uno (5V Power), Pushbutton, LED, Resistor
* **Simulation Link:** (https://www.tinkercad.com/things/8XQAGcxPiAE-fantastic-kasi-lahdi)
## How to Run
1. Click any **Simulation Link** above to open the project in Tinkercad.
2. Click **Start Simulation** to test the circuit and view the code.
